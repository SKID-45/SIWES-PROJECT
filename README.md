HELP-DESK SYSTEM
ABOUT

The Help Desk System is a web application developed to help users report technical problems and allow administrators to manage reported issues.
This project was developed as part of my Student Industrial Work Experience Scheme (SIWES). The aim is to make reporting and managing IT-related problems easier and more organized.

PROJECT FEATURES
User login page.
User dashboard.
Admin dashboard.
Submission of technical problems and complaints.
Management of reported issues.
Simple and user-friendly interface.

TECHNOLOGIES USED
React.js
JavaScript
CSS
Node.js
Axios
Firebase
Git and GitHub

HOW TO RUN IT
1. Clone the repository
bash
git clone https://github.com/SKID-45/SIWES-PROJECT.git

2. Enter the project folder
bash
cd SIWES-PROJECT

3. Install dependencies
bash
npm install

4. Start the application
bash
npm start


The application should open at http://localhost:3000.

AIM OF THE PROJECT
To create a platform where users can report technical issues and administrators can manage those issues easily.
